Smart Agent is a conversational workspace for creating and refining AI images and videos. Instead of treating every generation as an isolated form submission, it keeps your prompt, references, settings, results, and follow-up requests together in one chat.

## Choose the output you need

The composer supports three output modes:

- **Auto** lets the agent decide whether an image or video best matches the request.
- **Image** focuses the conversation on image generation and reference-based editing.
- **Video** enables text-to-video and image-to-video workflows.

You can start with a written idea, attach reference media, or combine both. The agent receives the selected mode and generation settings with the message, so follow-up requests stay grounded in the same task.

## Models available today

Smart Agent currently connects one image model and three video models through a shared interface:

- **GPT Image 2** for image generation, editing, restyling, and combining references.
- **MiniMax H3** for high-resolution text-to-video and image-to-video creation.
- **Seedance 2.5** for flexible video duration, reference frames, and audio-capable output.
- **Seedance 2.0** for text-to-video and image-to-video workflows up to 1080p.

The available duration, resolution, aspect ratio, and reference controls change with the selected model. Pricing is calculated from the validated settings when a generation tool runs.

## Refine instead of restarting

A useful first prompt describes the subject, action, setting, visual style, camera, and intended format. The conversation becomes more valuable after the first result: you can ask the agent to preserve what works and change only what does not.

For example:

> Keep the product and lighting from the previous result. Make the camera movement slower, reduce the background activity, and end on a clean centered pack shot.

That is easier to reason about than copying settings into a new form for every attempt.

## Use references deliberately

Reference images help with subject identity, composition, colors, and visual direction. Video, image, and audio references can also guide supported video workflows. A reference is most effective when the prompt explains what to borrow from it:

- “Keep the product shape and label layout.”
- “Use this image for the opening composition.”
- “Match the pacing, but use a brighter studio setting.”

Do not assume that attaching a file explains the creative intent by itself.

## Add a creative skill when it helps

Prompt Skills provide focused creative guidance for workflows such as product reveals, cinematic ads, UGC, testimonials, SaaS promotion, real estate, and social content. A Skill improves how the agent interprets and structures the request; it does not unlock unregistered models, bypass billing, or grant extra tools.

## A practical workflow

1. Select Auto, Image, or Video.
2. Choose a model and the supported output settings.
3. Attach only the references that materially guide the result.
4. Describe the subject, action, camera, lighting, and destination format.
5. Generate the first take.
6. Continue in the same conversation with one or two precise changes at a time.

The goal is not a longer prompt. It is a clearer creative decision at each turn.
