Video Agent 是一个通过对话创作和迭代 AI 图片、视频的工作空间。每次生成不再是彼此孤立的表单提交；提示词、参考素材、生成参数、结果和后续修改都会保留在同一个会话里。

## 先选择需要的输出

Composer 支持三种输出模式：

- **自动**：让 Agent 根据任务判断应该生成图片还是视频。
- **图片**：专注图片生成和基于参考图的编辑。
- **视频**：启用文生视频和图生视频工作流。

你可以只输入创意，也可以上传参考素材，或者组合使用。选择的模式和参数会随消息一起进入会话，因此后续修改仍然围绕同一个任务展开。

## 当前支持的模型

Video Agent 目前通过统一入口连接一个图片模型和三个视频模型：

- **GPT Image 2**：图片生成、编辑、风格转换和多参考图组合。
- **MiniMax H3**：高分辨率文生视频和图生视频。
- **Seedance 2.5**：更灵活的视频时长、参考帧和音频输出能力。
- **Seedance 2.0**：最高支持 1080p 的文生视频和图生视频工作流。

可选时长、分辨率、画幅比例和参考素材会根据模型变化。生成工具真正执行时，系统会根据服务端验证后的参数计算积分。

## 在结果上继续修改

一条有效的初始提示词通常包括主体、动作、环境、视觉风格、镜头和最终使用格式。第一次结果出来后，对话的价值会更明显：你可以保留已经正确的部分，只修改不满意的部分。

例如：

> 保留上一版的产品和灯光。让镜头移动更慢，减少背景中的活动元素，最后停在干净、居中的产品定格画面。

相比每次重新填写表单，这种方式更容易保持创作方向一致。

## 明确参考素材的作用

参考图可以帮助保持主体身份、构图、颜色和整体视觉方向。受支持的视频工作流还可以使用图片、视频或音频参考。上传素材时，最好在提示词里说明需要借鉴什么：

- “保持产品外形和标签布局。”
- “用这张图片作为开场构图。”
- “参考这个节奏，但改成更明亮的影棚环境。”

不要假设上传文件本身就已经表达了完整的创作意图。

## 在合适的时候使用创意 Skill

Prompt Skill 可以为产品揭幕、电影感广告、UGC、用户证言、SaaS 推广、房地产和社媒内容等工作流提供更聚焦的创意指导。Skill 会改善 Agent 理解和组织需求的方式，但不会解锁未注册模型、绕过积分或授予额外工具。

## 一个实用工作流

1. 选择自动、图片或视频模式。
2. 选择模型和该模型支持的输出参数。
3. 只上传真正影响结果的参考素材。
4. 描述主体、动作、镜头、灯光和目标格式。
5. 生成第一版。
6. 在同一个会话中，每次只提出一到两个明确修改。

重点不是写得更长，而是在每一轮做出更清楚的创作决定。
