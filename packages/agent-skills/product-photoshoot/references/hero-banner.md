# Hero Banner Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use for website, email, landing page, and campaign headers. Default aspect ratio: `16:9`; use `3:1` only if the target surface explicitly needs panoramic art.

## Composition

- Product remains the first-read subject.
- Leave usable copy space only when requested; otherwise build a complete visual banner.
- Keep hero object inside central safe area so responsive crops retain it.
- Background must support product contrast and brand tone.

## Quality Gate

Reject if the product is pushed to a corner, the banner depends on illegible text, or it becomes a generic atmospheric background.
