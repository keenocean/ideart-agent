# Pinterest Pin Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use for vertical 2:3 Pinterest-native product visuals. Default aspect ratio: `2:3`.

## Composition

- Tall editorial composition with product in the upper or central third.
- Moodboard-like supporting textures, ingredients, room detail, or styled props.
- Strong clear silhouette; avoid tiny packshots.
- Text only when the pin concept depends on a headline; then use `gpt-image-2`.

## Prompt Template

```text
[SUBJECT]
<product> as pinnable hero.

[PINTEREST AESTHETIC]
Vertical 2:3 editorial still-life, aspirational but shoppable, tactile surface, soft palette.

[COMPOSITION]
Layered visual path from product to supporting props; safe margins for crop; no clutter.

[LIGHTING]
Soft natural light, warm or neutral depending on brand, realistic shadow.

[OPTIONAL TEXT]
<exact short headline if requested; otherwise no added text>.
```

## Quality Gate

Reject if it looks like a generic ad banner, has fake CTA buttons, or wastes most of the frame on empty color.
