# Conceptual Product Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use for surreal, CGI-style, levitating, splash, sculptural, or premium DTC product imagery. Default aspect ratio: `1:1` or `4:5`.

## Concept Types

- Levitation: product suspended with realistic shadow logic.
- Splash/freeze: liquid, powder, ingredient, or debris motion around product.
- Sculptural plinth: premium object staged as gallery artifact.
- Material metaphor: product surrounded by visual elements that express USP.
- Scale play: oversized product in miniature environment.

## Quality Gate

Reject if spectacle hides the product, materials look like random decoration, or physical effects are impossible in a distracting way.
