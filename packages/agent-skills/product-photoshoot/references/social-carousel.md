# Social Carousel Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use for 3-10 connected IG, LinkedIn, or Facebook slides. Default aspect ratio: `4:5`; use `1:1` when requested.

## Slide System

1. Hero hook: product + single idea.
2. Feature or benefit visual.
3. Detail / ingredient / material macro.
4. Use-case or lifestyle proof.
5. Close or CTA visual.

Repeat or compress depending on requested slide count.

## Locked System

- Same palette, lighting language, surface family, type treatment, and crop logic across all slides.
- Product scale stays consistent.
- One idea per slide.
- If text is needed, use short exact headlines and `gpt-image-2`.

## Prompt Template

```text
[CAROUSEL SYSTEM]
<palette, typography case, surface, lighting, product scale>.

[SLIDE <n> / <beat>]
<one visual idea, product role, exact text if any>.

[CONSISTENCY]
Match all prior slides in color, lighting, crop rhythm, and product fidelity.
```
