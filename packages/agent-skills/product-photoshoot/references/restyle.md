# Restyle Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use to transform an existing image's mood, season, palette, surface, or lighting while preserving subject and composition. Always use the existing image as `image_urls`.

## Locked Elements

- Product identity, shape, label, color, material, and scale.
- Main composition and crop.
- Human identity if a person is present.
- Any real on-product text.

## Editable Elements

- Lighting direction and warmth.
- Background material or seasonal environment.
- Surface, props, color palette, shadow mood.
- Premium, playful, clinical, warm, festive, editorial, or minimal tone.
