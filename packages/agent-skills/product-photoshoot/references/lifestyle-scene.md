# Lifestyle Scene Mode

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Use when the product needs a real environment, action, mood, or use context. Default aspect ratio: `4:5`; use `9:16` for story/reel covers and `1:1` for square feed.

## Prompt Template

```text
[SUBJECT]
<product>, accurately preserved from reference when supplied.

[SCENE]
<environment tied to product use: kitchen, bathroom counter, gym, cafe, desk, outdoor, travel>.

[HUMAN INTERACTION]
Hands or partial person only if useful; product remains large and legible.

[COMPOSITION]
Lifestyle editorial product scene, product in active use, natural crop, no clutter, clear hero scale.

[LIGHTING]
Warm directional environmental light, shallow depth of field, realistic contact shadows.

[BRAND INTEGRATION]
Palette and props support the brand without adding competitor signals.

[QUALITY CONSTRAINTS]
Photoreal, believable environment, accurate product, no stock-photo stiffness.
```

## Rules

- Product appears in the foreground or user action zone, never as background decoration.
- Use props only when they explain the use case.
- Avoid fake smiles, exaggerated influencer posing, and unrelated lifestyle clutter.
