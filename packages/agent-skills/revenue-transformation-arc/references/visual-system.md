# Visual System

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

This reference locks the dark-grid motion-graphic system for the Revenue-Transformation Arc.

## Canvas

- Background: `#0d0d0d` charcoal, never pure black.
- Texture: grunge/dust/noise overlay at 10-15% opacity.
- Grid: 1 px white lines, about 60 px spacing, 8% opacity.
- Type: Anton or Bebas Neue for impact words; Montserrat Bold or Roboto Condensed for sub-captions.

## Semantic Color Syntax

| Role           | Hex       | Use                                         |
| -------------- | --------- | ------------------------------------------- |
| Pain / before  | `#FF3B3B` | Problem state, current pain, before-number. |
| Money / result | `#39FF14` | After-number, revenue, CTA highlight.       |
| Neutral text   | `#FFFFFF` | Captions and narration.                     |
| Services       | `#FFD600` | Pillars and action items.                   |
| Scale          | `#00AAFF` | Magnitude claims and impressive numbers.    |

## Block Layouts

- Hook: before number red, arrow/cut, after number green, time period white; no voiceover.
- Context: logo lower-third with white/yellow identity line.
- Problem: full-screen word-by-word caption barrage; impact words red.
- Agitation: shoulder-framed talking head or annotation circles.
- Solution: green schema or method diagram.
- Pillars: yellow icon + one noun phrase, 3-5 pillars total.
- Proof: testimonial/result card with green number.
- Credibility: blue scale number.
- CTA: green keyword box, white support copy, end logo lockup.

## Motion

- Hard cuts with SFX hits in the first 24 seconds.
- Word-by-word captions pop 50-80 ms after utterance.
- Hook cut needs a whoosh plus impact hit, 60-80 ms.
- Average shot length about 3.3 seconds; hook shots no longer than 2 seconds.

## Claim Safety

All revenue figures, time windows, scale claims, and testimonials must be real and client-specific. If not supplied, stop and ask for the facts instead of filling placeholders.
