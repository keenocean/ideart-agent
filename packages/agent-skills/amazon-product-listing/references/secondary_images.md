# Reconstructed Secondary Image Rules

This file is a reconstructed functional reference inferred from `SKILL.md` and common Amazon listing patterns. It is not an original creative platform side file.

## Default 5-Image Carousel

Generate downstream from `main:final`, all `1:1`, `resolution="2K"`.

1. Infographic: 3-5 feature/benefit callouts with icons and short labels.
2. Multi-angle: front, side, back, detail, and scale view in one clean layout.
3. Detail shot: macro or close crop showing material, mechanism, texture, ingredient, port, seam, or finish.
4. Lifestyle: product in a credible use context with target user or environment.
5. What's in the box: neatly arranged included items, no non-included props.

## General Principles

- Every image must preserve the exact product identity from `main:final`.
- Use one unified design system across the set: palette, typography, icon style, line weight, and spacing.
- Prioritize mobile readability: short headline, big product, minimal text.
- Avoid medical, legal, performance, sustainability, or quantified claims unless supplied by the user or visible on packaging.
- Put the product in the first visual hierarchy tier on every image.
- Keep text out of the outer 5% margin to avoid marketplace cropping.

## Typography

- Use crisp sans-serif type with high contrast.
- Use no more than one headline plus 3-5 short callouts per image.
- Prefer sentence case or title case; avoid tiny body copy.
- Never invent ratings, awards, warranties, certifications, prices, or promo claims.

## Compliance Guard

Secondary images may use backgrounds, people, props, text, and diagrams, but must not misrepresent what is included, make unsupported claims, or alter packaging.
