# Reconstructed Category Conventions

This file is a reconstructed functional reference inferred from `SKILL.md`. It is not an original creative platform side file.

## Beverage / Food

- Main: front-facing can/bottle/box/pouch on pure white; keep flavor and label exact.
- Secondary: taste/texture cues, serving suggestion, ingredient tiles, pack contents.
- Avoid: health/diet claims not printed on packaging or provided by user.

## Beauty / Skincare / Wellness

- Main: package and container cleanly visible; no model face on main unless category requires it.
- Secondary: texture macro, routine steps, ingredient highlights, bathroom/vanity lifestyle.
- Avoid: medical/cure claims, before-after transformations, invented dermatologist approval.

## Electronics / Gadgets

- Main: device front/three-quarter on white; include cable/accessories only if included.
- Secondary: ports, scale, compatibility, setup flow, screen/UI mockups only when provided.
- Avoid: fake app screens, fake certifications, invented battery/runtime specs.

## Apparel / Footwear / Accessories

- Main: full product on white; model or ghost mannequin when appropriate.
- Secondary: fit, fabric detail, size chart, styling/lifestyle, color variants only if included.
- Avoid: lifestyle main image, cropped item, misleading bundles.

## Home / Kitchen / Tools

- Main: product only on white, 3/4 angle for depth.
- Secondary: in-room/in-use context, scale, material, included parts, installation/use sequence.
- Avoid: showing unsupported installation hardware or extra decor as included.

## Baby / Kids / Pets

- Main: product only; keep safety-relevant parts visible.
- Secondary: gentle lifestyle, size/age compatibility only if verified, materials, cleaning/use.
- Avoid: unsafe use, unsupported safety certifications, risky sleep/medical claims.

## B2B / Industrial

- Main: product only on white; show serial/variant details only when visible.
- Secondary: spec grid, use case, rugged detail, compatibility, packaging contents.
- Avoid: unverified compliance standards or performance claims.
