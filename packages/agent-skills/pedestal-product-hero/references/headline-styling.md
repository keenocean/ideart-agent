# Headline Styling

Reconstructed reference file. This is not an original creative platform side-file; it was rebuilt from `SKILL.md` contract requirements after exact public-source searches found no usable original.

## Policy

Default to no headline. If the user asks for text, include exactly one headline and nothing else.

## Headline Block

```text
OPTIONAL HEADLINE:
Place one short headline in the upper third of the warm beige backdrop, centered above the product with generous negative space.
Set it in a modern serif, medium weight, slightly open letter spacing, dark warm brown #3B2A1F.
Break into two natural lines at a phrase boundary.
No subline, no CTA, no badge, no box, no shadow, no outline.
Text exactly: "[HEADLINE LINE 1] / [HEADLINE LINE 2]".
```

## Copy Rules

- Maximum 8 words total.
- No exclamation marks.
- No hype: "best ever", "amazing", "must-have", "sale".
- Use noun-phrase or quiet declarative language.
- For non-English diacritics, use `gpt-image-2`.

## Sample Shapes

- `Quiet energy / Daily ritual`
- `Clean crunch / Simple ingredients`
- `Morning made / Softer`
- `Made from / The good stuff`
- `Pure comfort / Every scoop`
