# Spillage Rules

Reconstructed reference file. This is not an original creative platform side-file; it was rebuilt from `SKILL.md` contract requirements after exact public-source searches found no usable original.

## Purpose

Spillage proves what is inside the package. It must match the product's own contents and never leak shapes/colors from a reference layout image.

## Content Mapping

- Cereal/crispies: round tan-beige pieces, matte, irregular clusters.
- Granola: oat flakes, nut fragments, toasted clusters; no chocolate unless specified.
- Powder: one small soft mound, light dusting, maybe a subtle scoop trail.
- Capsules/tablets: exact color and shape from product label or description.
- Nuts/seeds: named nut/seed only, true color and size.
- Dried fruit: named fruit and color only.
- Liquid: avoid spill; use a single glass/bowl element only when the product category requires it.

## Distribution

- 2-3 loose clusters of 8-15 pieces around the pedestal base.
- A few stragglers.
- Organic asymmetry.
- Never a tidy ring, wreath, border, or radial pattern.

## Negative Block Template

```text
SPILLAGE CONSTRAINT:
Only show [exact contents]. NO [wrong shape/color from reference], NO berries, NO leaves, NO chocolate, NO cubes, NO unrelated powders, NO decorative props.
```

## Ask Gate

If the product contents cannot be inferred from the package or brief, ask the user instead of guessing.
