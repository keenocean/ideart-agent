# Text Flashes

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Text flashes are the voice of the reel: 1-2 words, all caps, hard in/out, underline streak, no fades. One flash every 6-8 seconds.

## Word Bank

- LET'S GO
- GAME ON
- SWING IT
- HUSTLE
- RISE UP
- ALL IN
- LOCKED IN
- BIG MOMENT
- NO FEAR
- TEAM {TEAM_NAME}
- {TEAM_NAME} STRONG
- UNSTOPPABLE

## Placement

- First flash during setup/readiness, not on the first frame.
- Slow-mo flash on anticipation or celebration, not a contact frame.
- Keep within 980 px width on a 1080 canvas, including stroke and letter spacing.
- Resolve font size before positioning underline streak.

## Rendering Rule

PNG overlays on YUV video must be tagged `format=yuva444p` so alpha survives the ffmpeg overlay chain.
