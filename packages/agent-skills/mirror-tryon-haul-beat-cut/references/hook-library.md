# Mirror Try-On Hook Library

Status: reconstructed from `SKILL.md`; not the original creative platform side file.

Hooks are static overlays in the upper third for about 2.5 seconds. Lowercase is
preferred; use one emoji at most.

## Default

- `outfit picks i can't stop wearing ✨`

## Interchangeable Options

- `mirror haul favorites ✨`
- `three looks, zero overthinking`
- `saved these for the weekend`
- `the try-on that convinced me`
- `which one would you keep?`
- `outfit picks — link in bio`
- `quick haul before i go`

If the user insists on a CTA, fold it into the hook and hold it slightly longer.
Do not add an outro card.
