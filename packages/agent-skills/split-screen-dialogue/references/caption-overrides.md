# Split-Screen Caption Overrides

Status: reconstructed from `SKILL.md`; not the original creative platform side file.

## Default

- preset: `clean-bold`
- font: `DM Sans`
- appear_mode: `word`
- placement: lower safe band over the full vertical frame
- CTA/end-card scene: `mute_captions: true`

## Brand Register Overrides

| Register          | Preset            | Font      | Notes                                   |
| ----------------- | ----------------- | --------- | --------------------------------------- |
| premium tech      | `clean-bold`      | `DM Sans` | default                                 |
| playful chaos     | `pop-punch`       | `Anton`   | only if brand is intentionally loud     |
| luxury minimal    | `editorial-clean` | `Alice`   | slower pacing, less bounce              |
| friendly consumer | `soft-pill`       | `DM Sans` | rounded background, low contrast motion |

Never place captions inside the video generation frame. They are assembly-layer
captions only.
