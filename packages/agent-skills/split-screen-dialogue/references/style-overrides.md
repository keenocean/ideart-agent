## Cinematic Override

Use only for "cinematic" briefs:

- keep the exact top/bottom split-screen identity
- richer contrast and lensing

## Studio Override

Use only for "studio" briefs:

- clean creator studio, soft key light, plain backdrop
- no shelves or branded wall graphics
- wardrobe remains casual, not presenter-formal

## Non-Overrides
