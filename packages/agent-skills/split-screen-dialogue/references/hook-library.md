# Split-Screen Dialogue Hook Library

Status: reconstructed from `SKILL.md`; not the original creative platform side file.

Use one woman-led challenge/setup/provocation as the first spoken line. The split
screen is visible from frame 1.

## Formulas

- "Be honest. When was the last time you actually [did desired action]?"
- "You said you wanted [outcome], but you're still doing [old behavior]."
- "I can tell exactly why [pain point] keeps happening."
- "If [task] takes you more than [time], you're using the wrong system."
- "Wait. You're solving [problem] manually?"
- "That's not a [category] problem. That's a [root cause] problem."
- "You don't need another [generic tool]. You need [specific mechanism]."

## Response Beat

The man does not steal the hook. He reacts silently for 0.5-1s, then answers
with curiosity, mild defensiveness, or a short question.

## Hook QA

Reject hooks that:

- introduce a logo or product before the conversation starts
- sound like a testimonial opener
- require on-screen explanatory text
- are longer than one natural sentence
