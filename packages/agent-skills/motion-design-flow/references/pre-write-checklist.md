# Pre-write Checklist

Run this silently before each storyboard or scene-video prompt.

- Mode selected: MDCM, Product Reel, MDH, MDT, or MDI.
- Image branch resolved: attached image role, generated foundation, product photo, or no-image path.
- Required asset ids resolved through `list_assets` / `get_asset`.
- For MDCM Stage B, selected moodboard asset id is included in `image_urls`.
- Text count matches user-provided copy exactly.
- All visible text satisfies the min-text rule.
- Non-product modes avoid photoreal humans and photographic stock registers.
- Visual World Lock has subject, material, style, and six varied scenes.
- Palette lock has 2-3 colors with hex codes and no hidden extra accent.
- Every shot has a named camera move.
- Every junction has a named transition with medium/details.
- Sheet chrome tier chosen by register.
- Tail pause freezes the final frame; no fade.
- Cliche ban list checked against the proposed visual world.
