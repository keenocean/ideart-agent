# Visual World Lock

Before storyboarding, define four values and reuse them in every panel.

## Lock Fields

- Subject lock: the recurring motif or hero form.
- Material lock: the tactile substance that expresses the brand idea.
- Style lock: lighting, render register, lens/poster attitude, and atmosphere.
- Scene variation: six different contexts inside the same world.

## Derivation Procedure

1. Extract the brand or concept nouns.
2. Replace generic genre defaults with a specific material metaphor.
3. Choose one visual register from the reference tier matrix.
4. List six distinct scenes that share the same subject/material/style.
5. Ensure at least three framing scales across the six scenes.

## Injection Template

Use this sentence in storyboard prompts:

`VISUAL WORLD LOCK: subject = [motif]; material = [material identity]; style = [lighting/register/atmosphere]. Every panel stays inside this world while changing scene context and framing scale.`

## Failure Check

If panels could be shuffled into unrelated campaigns, the lock failed. If panels are one set at six timestamps, scene variation failed.
