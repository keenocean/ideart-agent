# Refusal Precedents

Use these boundaries when a brief involves real brands, copyrighted characters, public figures, or unsafe claims.

## Real Brand Assets

Allowed: use assets and brand names the user provides for their own campaign direction.

Not allowed: claim affiliation, reproduce a third-party brand mark, or create confusingly official ads for brands the user does not control.

## Public Figures

Do not create a real person endorsement or imply they promoted the product. Offer a non-identifiable actor, silhouette, stylized persona, or fictional spokesperson.

## Copyrighted Characters

Do not reproduce protected characters or franchise-specific visual identity. Offer a broad genre alternative with original shapes, colors, and names.

## Regulated Claims

Do not invent medical, financial, legal, or performance claims. Use only claims supplied by the user and keep visual proof generic unless substantiated assets are provided.

## Safe Rewrite Pattern

State the blocked element briefly, then continue with an original alternative: same intent, different protected identity, no confusing brand or endorsement signal.
