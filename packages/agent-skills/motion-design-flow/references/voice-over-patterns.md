# Voice-over Patterns

Motion-design reels can run with no voice-over. Add voice-over only when the user asks for narration, explainer pacing, or ad copy that needs spoken timing.

## Pattern A: Sparse Brand Line

One short line at the opening or closing. Use for premium brand reels.

Example shape: `[brand truth]. [two-word close].`

## Pattern B: Three Beat Explainer

Three short sentences aligned to panels 01/03/05 or 02/04/06. Use for SaaS, product benefits, and process explanations.

## Pattern C: Data Narration

Metric first, implication second, action third. Use for infographic reels.

## Rules

- Spoken copy should not duplicate every visible text string.
- Keep each line short enough to breathe over 2-3 seconds.
- Do not add legal, medical, financial, or performance claims beyond the user's provided claims.
- If captions are generated, they must not force tiny in-frame text; captions belong in the video caption layer, not inside storyboard art.
