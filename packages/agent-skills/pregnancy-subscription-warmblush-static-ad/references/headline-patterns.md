# Headline Pattern Library

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Headlines celebrate the milestone person or moment. Use clean bold rounded sans-serif; no bubbly fonts except inside offer stickers.

## Patterns

- `Celebrate [milestone person]`
- `A box for [milestone feeling]`
- `[Milestone] deserves a moment`
- `For the one becoming [new role]`
- `Gift the [milestone] glow`
- `A monthly moment for [recipient]`
- `Made for this chapter`
- `A little joy, every month`
- `For the people who love [recipient]`
- `The sweetest [milestone] surprise`

## Anti-Patterns

- Delivery-first: `Delivered every month`
- Feature-first: `Includes 8 premium items`
- Brand-first: `We made the best box`
- Hard urgency: `Only 24 hours left`
- Price-led: `$19.99 today`

## Five-Concept Suite Mapping

1. Product hero: broad milestone celebration.
2. Lifestyle emotion: recipient feeling line.
3. Gift-giver angle: line addressed to loved ones.
4. Social proof: real award/press proof if supplied.
5. Lifestyle Serif A/B: repeat the lifestyle emotion concept as an explicitly labeled serif-vs-sans test. Do not default the suite to serif; the control headline remains clean rounded sans-serif.
