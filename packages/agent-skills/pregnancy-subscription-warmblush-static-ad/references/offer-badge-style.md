# Offer Badge Style

Reconstruction notice: this file is reconstructed from `SKILL.md`; it is not an original creative platform side file.

Offer badges are optional and appear in only two of five ads.

## Shape And Placement

- Hand-drawn sticker or doodle burst, not a clean corporate pill.
- Slightly irregular edge, soft paper/sticker shadow.
- Place near product spread or upper corner so it reads last, not before the emotional headline.
- Keep badge small enough that headline and product remain dominant.

## Color

- Soft teal for free-gift offers.
- Warm pink or warm accent for discount offers.
- Gold/cream only for premium or award-adjacent emphasis.

## Type

- Bubbly or handwritten font is allowed only inside the badge.
- Keep text to 2-4 words.
- No hardcoded dollar prices.

## Allowed Copy

- `FREE GIFT`
- `15% OFF`
- `BONUS INSIDE`
- `FIRST BOX GIFT`
- `LIMITED BONUS`

Use only real offers supplied by the user.
