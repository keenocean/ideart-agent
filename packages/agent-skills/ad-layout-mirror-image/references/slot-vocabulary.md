# Ad Layout Slot Vocabulary

Status: reconstructed from `SKILL.md`; not the original creative platform side file.

Use concrete slot language when translating a reference ad into prose.

## Common Slots

- hero product: largest visual object, primary attention anchor
- hand/use moment: product being held, poured, opened, applied, or compared
- macro detail: texture, label, material, screen, ingredient, or mechanism close-up
- headline block: largest text zone
- subhead block: smaller explanation text
- proof badge: rating, review count, certification, guarantee, award
- offer chip: discount, bundle, free shipping, limited-time line
- CTA pill/button: action text or URL
- logo lockup: brand mark, usually corner or closing zone
- legal fine print: required disclaimer
- background field: color, gradient, tabletop, wall, room, sky
- negative space: intentionally empty area preserving readability

## Prose Pattern

"The reference uses [hero slot] occupying [area], with [headline block] in
[position], [badge] near [object], and [CTA] anchored [position]. Mirror that
slot hierarchy while replacing all reference brand/product content."
