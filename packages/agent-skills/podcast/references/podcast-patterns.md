# Podcast Patterns

Reconstructed reference file. This is not an original creative platform side-file; it was rebuilt from `SKILL.md` contract requirements after exact public-source searches found no usable original.

Use these structures as scaffolds for the episode plan. Replace topic, personas, and dialogue while preserving chunk continuity and pattern selection.

## SP1: Founder Contradiction

- Spine: host challenges the obvious founder story; guest reveals the hidden constraint.
- Chunks: A -> B -> A -> C -> A.
- Best for: startup, product, strategy, business origin stories.
- Dialog energy: curious host, precise guest.

## SP2: Investigative Deep-Dive

- Spine: a public belief is unpacked until the final missing fact reframes it.
- Chunks: A -> A -> B -> C -> A.
- Best for: cultural, science, market, or historical topics.
- Dialog energy: host asks short pressure questions; guest carries evidence.

## SP3: Comedic Expert Correction

- Spine: host states a naive take; guest keeps correcting it until both laugh at the real answer.
- Chunks: A -> C -> A -> B.
- Best for: explainer clips with a lighter tone.
- Dialog energy: restrained banter; no mugging.

## SP4: Confession To Framework

- Spine: one speaker admits a mistake; the other extracts a reusable lesson.
- Chunks: B -> A -> A -> C -> A.
- Best for: creator, founder, personal growth, tactical advice.
- Dialog energy: reflective, grounded.

## SP5: Debate With Soft Landing

- Spine: two hosts disagree, narrow the disagreement, then land on a more useful formulation.
- Chunks: A -> A -> C -> B -> A.
- Best for: opinion, strategy, philosophy, cultural identity.
- Dialog energy: firm but collegial.

## Pattern Selection Notes

- Use Pattern A whenever a line handoff matters.
- Use Pattern B when one speaker owns most of a chunk.
- Use Pattern C immediately after a reveal, joke, contradiction, or surprise statistic.
- Avoid using Pattern C twice in a row; it blunts the reaction beat.
