# PT-BR Script Template & Hook Library

Status: reconstructed from `SKILL.md`; this is not an original creative platform side file.

Use Brazilian Portuguese only. The voice is a young male peer enthusiast:
hyped-but-credible, warm, energetic, not a TV announcer.

## Timing Target

- Total: about 25s.
- Pace: about 2.5 words/second.
- Scene 1: 8s, max about 20 words.
- Scene 2: 5s, about 12 words.
- Scene 3: 9s, about 22 words.
- Scene 4: 5s, light VO or none.

## Four-Scene Template

### Scene 1 - Hook / Product Hero

```text
Procurando o [produto/kit] definitivo para [uso/audiência]?
Olha a qualidade desse [material] com [detalhe premium]!
```

Visual: slow push-in on the cleanest product hero photo.

### Scene 2 - Mechanism Macro

```text
Mas o melhor vem agora: [mecanismo] para você [benefício prático]!
```

Visual: extreme macro of snap, magnet, zipper, Velcro, clip, patch, button, rail,
or modular connector.

### Scene 3 - Attachment Payoff

```text
É o [resultado visual] com qualidade premium.
Fica pronto em segundos e muda totalmente o visual.
```

Visual: pull back from macro to mid-shot showing the accessory attaching to the
garment/product.

### Scene 4 - CTA

```text
Garanta o seu kit nas principais lojas online!
```

Visual: full assembled kit, muted captions, CTA pill.

## Hook Variants

```text
Procurando o kit definitivo para [ocasião]?
Quer transformar seu [produto] em segundos?
Já imaginou um [produto] com [mecanismo] de verdade?
Esse é o kit que muda tudo no seu [uso/visual].
Olha esse detalhe que faz toda a diferença.
```

## Mechanism Vocabulary

| Mechanism       | PT-BR phrase           |
| --------------- | ---------------------- |
| snap buttons    | `botões de pressão`    |
| magnets         | `ímãs internos`        |
| zipper          | `zíper reforçado`      |
| Velcro          | `fechamento em velcro` |
| clip rail       | `trilho de encaixe`    |
| removable patch | `patch removível`      |
| detachable hood | `capuz destacável`     |
| detachable cape | `capa removível`       |

On-screen CTA pill remains:

```text
COMPRE AGORA - ESTOQUE LIMITADO
```

## Hard Language Rules

- Brazilian Portuguese only.
- No English code-switching.
- No cold brand-robot language.
- No overpacked sentences.
- Prefer short direct clauses.
- Keep `Mas o melhor vem agora:` as a colon pause when possible.
