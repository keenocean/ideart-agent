# Claim Swap Rules

Reconstructed reference file. This is not an original creative platform side-file; it was rebuilt from `SKILL.md` contract requirements after exact public-source searches found no usable original.

## Purpose

When emulating a reference ad, every claim from the reference must be verified or replaced. The layout can be reused; the competitor's claim truth cannot.

## Claim Inventory Checklist

For each visible text block in the reference, classify it:

- Brand/name: replace with user's brand.
- Descriptive headline: adapt to user's product category.
- Objective feature claim: keep only if verified.
- Quantified claim: keep only with explicit proof.
- Regulated claim: remove unless the user's own label/spec says it.
- Footer/legal: rewrite to match the user's real conditions or omit.
- Decorative text: keep only if it is not a claim.

## Source Priority

1. User-provided product description or spec sheet.
2. Text visible on the user's product photo.
3. Existing brand/product website if provided in the conversation.
4. Brand voice inferred from pack design for non-claim language only.

## Never Carry Over Without Proof

- Sugar-free, fragrance-free, hypoallergenic, dermatologist-tested.
- Waterproof, sweatproof, fireproof, medical-grade.
- Battery life, charging speed, warranty duration.
- Shipping windows, discounts, inventory statements.
- Nutrition macros, ingredient exclusions, certification badges.
- Awards, ratings, review counts, "clinically proven".

## Swap Patterns

- Unsupported quantified claim -> qualitative truthful claim.
  - `24-hour hydration` -> `daily hydration support` if only hydration is verified.
- Competitor ingredient claim -> user's visible ingredient.
  - `with collagen` -> `with [ingredient visible on pack]`.
- Certification badge unsupported -> remove or replace with neutral category marker.
- Price/discount unsupported -> omit.

## Prompt Note

List the final approved copy in the image prompt and add: `Do NOT add extra claims beyond the listed copy.`
