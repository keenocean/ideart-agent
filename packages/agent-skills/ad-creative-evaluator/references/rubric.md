# Evaluation Rubric — Quick Reference

## Scoring scale

Use observable creative evidence, not predicted business results.

| Score | Label       | Evidence anchor                                                |
| ----- | ----------- | -------------------------------------------------------------- |
| 10    | Exceptional | Fully resolved execution with specific evidence for the score. |
| 9     | Excellent   | Very strong execution with only negligible limitations.        |
| 8     | Very good   | Strong execution with minor, identifiable improvements.        |
| 7     | Good        | Clear and functional, with meaningful room to improve.         |
| 6     | Adequate    | Understandable and usable, but not distinctive or consistent.  |
| 5     | Mixed       | Strengths and weaknesses have similar impact.                  |
| 4     | Weak        | Observable issues materially reduce creative clarity or trust. |
| 3     | Poor        | Several major execution problems are visible.                  |
| 2     | Very poor   | The dimension is barely functional.                            |
| 1     | Minimal     | Only a trace of the required dimension is present.             |
| 0     | Absent      | The dimension is observably absent or unusable.                |

Do not use 0 for missing evidence. Mark the dimension unassessed instead.

## Dimensions at a glance

### 1. Hook effectiveness

Does the first three seconds create a clear reason to continue?

- 9–10: immediate, specific attention mechanism with strong first-frame support;
- 5–6: understandable opening, but generic, delayed, or only partly supported;
- 0–2: no observable reason to continue.

### 2. Message clarity

Can the viewer identify the product, audience, and value?

- 9–10: one clear, quickly understood message;
- 5–6: the message is present but requires effort;
- 0–2: the message is absent or contradictory.

### 3. Visual quality

Do framing, continuity, legibility, and production choices support the message?

- 9–10: consistently clear and intentional;
- 5–6: usable with visible rough edges;
- 0–2: broken, illegible, or materially distracting.

### 4. Audience targeting

Do language, situation, proof, and objections fit the stated audience?

- 9–10: multiple specific choices support the audience fit;
- 5–6: broadly relevant but generic;
- 0–2: no observable audience fit or a clear mismatch.

### 5. Pacing and structure

Does each beat advance the argument at a comprehensible rate?

- 9–10: every beat has a clear role and the progression is easy to follow;
- 5–6: some dead time, repetition, or overload;
- 0–2: the structure is absent or cannot be followed.

### 6. CTA strength

Is the next action specific, visible, credible, and well timed?

- 9–10: one clear action supported by the preceding message;
- 5–6: present but generic, late, or weakly connected;
- 0–2: missing, contradictory, or not actionable.

### 7. Emotional resonance

Does the creative earn an identifiable response such as interest, trust, desire, or relief?

- 9–10: the response is strongly supported by specific creative choices;
- 5–6: informative but emotionally limited or uneven;
- 0–2: no intended response is evident, or the execution damages trust.

### 8. Sound-off comprehension

Can the core message and action be understood without audio?

- 9–10: visuals and captions preserve the complete argument;
- 5–6: the viewer can understand the gist but loses important detail;
- 0–2: the ad is not understandable without audio.

## Overall score formula

For eight assessed dimensions, use the unweighted arithmetic mean:

```text
Overall = (Hook + Message + Visual + Audience + Pacing + CTA + Emotion + SoundOff) / 8
```

If any dimension is unassessed, average only the assessed dimensions, label the result provisional, and list the excluded dimensions. A provisional score is not directly comparable to a fully assessed score.

## Creative-readiness guide

| Overall | Creative decision                               |
| ------- | ----------------------------------------------- |
| 8.5+    | Ready for a controlled test.                    |
| 7.0–8.4 | Apply minor fixes, then test.                   |
| 5.5–6.9 | Revise the two weakest dimensions first.        |
| 4.0–5.4 | Major creative rework is needed before testing. |
| < 4.0   | A new concept may be more efficient.            |

This guide describes creative readiness only. Media-spend decisions require actual campaign data.
