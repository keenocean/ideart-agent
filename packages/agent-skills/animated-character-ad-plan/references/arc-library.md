# Reconstructed Animated Character Arc Library

This file is a reconstructed functional reference inferred from `SKILL.md`. It is not an original creative platform side file.

## How To Choose

Pick the arc whose climax can make the product benefit literal and visible. The product should be the absurd object, the transformation reward, or the bridge to the payoff.

## 1. Curiosity-Hook -> Escalation -> Surprise Transformation

Best for: energy, beauty glow-up, productivity boost, flavor reveal, anything that feels like a power-up.

Beat map:

1. Characters discover a mysterious object or signal.
2. Small test creates escalating curiosity.
3. One hesitant character commits.
4. Transformation reveals the benefit.

Climax rule: the product causes or symbolizes the visible upgrade.

## 2. Underdog Wants Something -> Obstacle -> Clever Win

Best for: problem-solving products, tools, learning apps, performance helpers.

Beat map:

1. Underdog wants a simple goal.
2. Obstacle blocks them in a funny physical way.
3. Product appears as clever workaround.
4. Underdog wins with a satisfying visual payoff.

Climax rule: the product turns weakness into advantage.

## 3. Setup -> Misdirection -> Comedic Twist

Best for: "not what you expected", surprising flavor, unexpected use case, challenger brands.

Beat map:

1. Establish familiar mundane situation.
2. Characters misread the product or moment.
3. Build expectation in one direction.
4. Twist reveals the true benefit or gag.

Climax rule: the twist must still sell the product, not only the joke.

## 4. Emotional Micro-Arc: Loneliness -> Connection

Best for: sharing, comfort, community, gifting, family, food, wellness.

Beat map:

1. Character isolated in a mundane setting.
2. Product creates a small invitation or bridge.
3. Others respond, cautiously then warmly.
4. Group payoff: comfort, belonging, shared ritual.

Climax rule: product is the bridge, not a random prop.

## 5. Rivalry -> One-Upmanship -> Mutual Payoff

Best for: duo products, shareable snacks, games, apps, features with collaboration.

Beat map:

1. Two characters compete over a small goal.
2. Escalation gets funnier and more absurd.
3. Product changes the contest.
4. Both win or discover sharing is the bigger payoff.

Climax rule: rivalry resolves through the product benefit.

## 6. Day-In-The-Life Loop -> Absurd Disruption -> New Normal

Best for: routine-changing products, subscriptions, home services, productivity apps.

Beat map:

1. Show a repeated boring loop.
2. Absurd object/event interrupts the loop.
3. Characters test the new path.
4. New normal is visibly better and funnier.

Climax rule: the product replaces the frustrating routine.

## Output Requirements Per Arc

- Name the chosen arc.
- Justify it in one sentence by product benefit.
- Map each scene to one beat.
- Keep dialogue-free-first unless user asks otherwise.
- Ensure every scene has one clear visual action.
