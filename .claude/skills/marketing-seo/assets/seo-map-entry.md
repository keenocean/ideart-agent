## SEO map entry template

Copy one entry per route and locale into `docs/marketing-pages-seo-map.md`. Remove instructional placeholders rather than publishing them.

```md
## <entity-id> · <locale>

- Route: `/<locale-free-path>`
- Entity: `<tool|model|directory|landing>:<slug>`
- Locale: `<en|zh>`
- Publication: `<listed|unlisted|hidden>`
- Availability: `<live|beta|coming-soon>`
- Indexing decision: `<index|noindex|blocked>`
- Primary intent: <one user need>
- Query cluster: <evidence-backed terms; no invented volume>
- User stage: <discover|compare|create|troubleshoot|buy>
- Canonical path: `/<locale-free-path>`
- Indexable alternates: `<locale:path>`
- Adjacent pages: <routes>
- Cannibalization boundary: <why this page is distinct or should consolidate>
- Required visible evidence: <examples, prompts, specs, limitations>
- Claim sources: <runtime keys or official URL + reviewed date>
- Inbound links: <source route → natural anchor>
- Outbound/related links: <destination and reason>
- OG asset: <asset id/path, alt, dimensions>
- Structured data: <allowlisted types or none>
- Actual content updated at: <date or unknown; not merely review time>
- Reviewed at: <date>
- Repository checks: <pass/fail/pending>
- External verification: <done/pending/not available>
- Notes/risks: <remaining uncertainty>
```
