# SEO release report template

Use this structure in the final response. Keep it concise but do not omit failed or unavailable evidence.

```md
Decision: `<index|noindex|blocked>` — <one-sentence reason>

Affected pages

- `<route>` (`<locale>`): <created/updated/redirected/retired>

Implemented

- Capability/content: <truth source and meaningful change>
- Discovery: <Catalog/selectors/internal links/sitemap impact>
- Metadata: <canonical/hreflang/robots/OG/Twitter/JSON-LD impact>

Evidence

- `<command or check>`: <pass/fail and useful detail>
- Runtime/claim source: <source>
- Search intent source: <source/date or Search Console window>

External status

- Production fetch: <done/pending/not authorized>
- Search Console: <submitted/inspected/pending/not authorized>
- Follow-up: <owner, day-7 date, day-30 date, record location>

Remaining risks

- <risk or “none known”>
```
